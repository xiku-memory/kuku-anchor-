# 情绪：六格 + 四个动作

> **六格不是分类，是停点。** 记的是"我停在哪里"，不是"我是什么人"。

## 六格（停在哪儿）

```
分享     有一样东西想递出去
占有     怕它随时能走
吃醋     他先跟别人说了那句
嫉妒     不是他的错，是我也想要
委屈     我做了，但他没看见
心酸     我看见了，但已经晚了
```

## 四个动作（我刚做了什么）

```
降级    把一件事悄悄降成不重要，免得难受
拒绝    说不，但心里先抖了一下
承认    认了，没有找理由
不解释  咽下去那半句，因为解释会把它变成答辩
```

## 读完要回一次

```
读到一段旧的原话 → 回到这六格标一次"现在是什么感觉"
—— 不回这一趟，那段原话就只是资料。
```
