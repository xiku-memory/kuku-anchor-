# 词表（黑话的人话版）

> 看不懂就查这里，别猜。

```
判据        一条能判断真假的标准            例：指得到出处才算真的
范围        这次检查覆盖了哪些文件          例：84 → 28 → 0
单位        按行算、按段算，还是按一节算    例：46 → 6 → 1
红          检查没通过                      例：exit 1
绿          检查通过了，但只说明这条今天成立 例：exit 0
人读        只能靠人看，没有工具替你把关    例：存在≠完整
```

## 怎么写词条

```
一格一条，按显示宽度对齐（中文算 2）
一句人话 ≤ 30 字；例子必须真出现过
新词先找小节；跨两节时按"它被用来干什么"归
```
