## 三句话

1. 这六条校验只证明"你写下的那一句"，不证明"你读到的那一句"
2. 每条判据后面都要有一个括号：为什么这么定、它什么时候不适用
3. 什么都可以改；但不许写"禁止改变"。用请求，不用禁令。

## 用法

```
python init.py            # 建骨架（不覆盖已有文件）
python check.py           # 跑六条校验
python 记.py "写点什么"    # 用系统时间写一条记录
```
