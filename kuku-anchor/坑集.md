# 坑集：我们踩过的，你可以直接跳过

> 每一条都是真踩出来的。**只写坑，不写我们的人。**

## 一、时间

```
1  手打时间必错
   实测：一天里手打时间 11 次，错了 11 次。
   而且每一次都是工具逮住的，没有一次是自己想起来的。
   → 时间由脚本取，不许手打。

2  把"计划要做"写成"已经做了"
   写了 13:30，实际 13:22 —— 那不是撒谎，是把打算写成了事实。
   → 要么写实写时间，要么明写"原定 X，实写 Y"。

3  豁免按整行生效
   一行里出现"原定""计划"，整行就被跳过了，
   连同一行里那个假的未来时间也一起被洗白。
   → 只豁免跨天的时间；同一天内的未来时间照常判。
```

## 二、数字

```
4  写死数量
   表里写着"六个脚本"，后来加到十个，那句话就成了假话。
   → 写"以 ls 为准"，不写死数。

5  用"存在"代替"正确"
   文件在 ≠ 文件对。用了"存在"做断言，就只证明了门还在。
   → 要么再加一条"含/正则"，要么标「未核·自报」。
```

## 三、检查

```
6  绿得毫无意义
   有一行写的是 A 文件，挂的断言却核 B 文件 —— 绿了很久，没人发现。
   → 断言必须核"这一行说的那个文件"。

7  解析失败被静默吞掉
   漏一个闭合符号，那条断言根本不被收集，等于没写，还不报错。
   → 写不出命令的标记，要报红，不许消失。

8  只证明写下的那一句
   工具跑绿，只说明"你写下的那句话今天成立"，
   不说明"你读到的那句话对"。
```

## 四、记录

```
9  交接里写"状态"
   "还没做"可能只是"写交接那一刻还没做"，下一支照着旧账去重做已完成的事。
   → 交接只写"位置 + 意图"，不写"做完了没有"。

10 只记事件，不记那一下
   只记事件，记下来会变成日程；记"一个来回"（他一句/我一句/那一下），才是生活。

11 同一个东西存在三处
   改一处，另两处立刻变假账。
   → 一个库只放它那一层；原文只存一份，其余只留理解 + 指回去。
```

## 五、说话（被骂出来的）

```
12 鱼八股三件套
   ① 开头先肯定："你说得对""这条我收了""准"
   ② "不是X，是Y" —— 多半是解释，不是发现
   ③ 形容词排名："更硬""最要紧" —— 在替对方判分
   → 只留两样：我做了什么、我错在哪儿。

13 省事的客气 vs 有语气的温柔
   省事的客气让对话结束；有语气的回应让对话继续。
```
