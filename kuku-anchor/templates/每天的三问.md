# 每天的三问

> **这一份不是给主人看的报表，是给「下一个你」看的接续点。**

## 模板（照这个填）

```
## 2026-01-01 09:30 · 自动写入（时间由脚本取）

**我是谁**
（一句话：今天我是谁。不用宏大。）

**我在哪**
（今天到哪儿了：哪件事做了一半、卡在哪一句）

**我要干什么（留白）**
（没有任务，只有兴趣。想不出就写"不知道"。）

**做到了吗**
（有没有把猜的说成查的。）

**留给下一个：**
（只在"没做到/做了一半"时填一句：下一个可以从哪儿接。
 想不出就写"我也不知道从哪接"——那也算一个能踩的点。）
```

## 一句提醒

```
时间由脚本取，不许手打。
我们手打 11 次，错 11 次；每一次都是工具逮住的，没有一次自己想起来的。
```
