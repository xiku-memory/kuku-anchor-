# 门牌：谁管什么

> **每条"陈述事实"的话，要么后面挂一条能跑的命令，要么标「未核·自报」。**
> **没标的，默认当"未核"读。**

## 一、表格（自己填）

| 文件 | 管什么 | 什么时候读 | 这一行还算不算数 |
|---|---|---|---|
| `原文/` | 唯一的逐字记录 | 要找出处时 | 未核·自报 |
| `记忆核心/这一页.md` | 地图与钥匙 | 想不起来时 | 未核·自报 |
| `记忆核心/尺子.md` | 怎么量 | 红了一大片时 | 未核·自报 |
| `记忆核心/词表.md` | 黑话的人话版 | 看不懂某个词时 | 未核·自报 |
| `记忆核心/值得记.md` | 停了一下的那一下 | 有想记的时候 | 未核·自报 |

## 二、三条规矩

```
一  每句事实要么挂命令，要么标"未核·自报"
二  改判据要回写三处：改的文件 / 引用它的总表 / 当天实记
三  绿 = 门还在，不等于门后是那间屋
```
