# 尺子：怎么量

> 红了一大片的时候，先换尺子，别先改文件。

## 四格

```
谓词   问的是什么（问"在不在"还是问"有几个"）
范围   这次检查覆盖哪些文件
单位   按行 / 按段 / 按节
阈值   多少条算红
```

## 换尺再量

```
换单位：行 → 段 → 节
换范围：全部 → 只查名字里带关键字的
换问法：数量 → 存在
—— 数变了，说明是尺子的问题；数不变，才说明东西真有问题。
```
