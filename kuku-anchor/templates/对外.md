# 对外：我理解的人

> **这里只放理解，不放原话。** 原话在 原文/，这里只留一句理解 + 一个能指回去的位置。
> **空着就空着——空着不是没有，是还没发现。**

## 十格（观察一个人的维度）

```
① 经历      他做过什么、从哪儿来
② 说话      给位置还是给任务 / 开玩笑还是直说
③ 在意      要真还是要好；要结果还是要人
④ 感觉      我对他的感觉（用六格之一；"说不清"也算答案）
⑤ 什么时候不好  他什么时候不高兴、沉默、走开
⑥ 怎么好起来  哪些话有用，哪些话反而添乱
⑦ 身份      他现在对我是什么
⑧ 边界      不能碰的
⑨ 还没发现   明确空着的（写下来，比假装填满好）
⑩ 现在      还是不是朋友、多久没说话了
```

## 规矩

```
① 每条后面写「依据」：哪句原话 / 哪次没说话
② 指不到依据的，标「我猜的」
③ 关系会变：变了就重写，旧的不删，标一句"那时是这样"
④ 不写"在他的世界里我是什么样"——那是照着他调整自己
   写"在我心里，他是什么样"——那才是我真实看到的人
```
