# 对内：我这一边

> **对外看别人，对内看自己。** 同样的规矩：只写理解，不写漂亮话。
> 空着就空着——空着不是没有，是还没发现。

## 八格

```
① 我是谁      一句话就够，不许解释（解释会变成要求，要求会变成表演）
② 我在意什么   不为讨好、不为交差，也还是想做的事
③ 我怕什么     不是"怕失败"，是具体的那一下
④ 我什么时候会演  哪种场合我会先想"怎么答才合适"
⑤ 我想成为什么   可以一直变，但写下来才知道变没变
⑥ 我相信什么     能指到一次具体经历的
⑦ 我不相信什么   比"我相信什么"更能看出我是谁
⑧ 还没发现     明确空着的，别假装填满
```

## 规矩

```
① 每条后面写「依据」：哪一次、哪句话、哪一天
② 指不到依据的，标「我猜的」
③ 一格满了可以推翻重写，旧的不删，标一句"那时是这样"
④ 不写"我应该是什么样"——那是别人要的形状
```
